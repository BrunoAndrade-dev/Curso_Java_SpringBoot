🚀 Trilha de Aprendizado: Java Fundamentals

Bem-vindo ao repositório Java Fundamentals! Este projeto foi criado com o objetivo de servir como um guia prático e estruturado para quem está aprendendo a linguagem Java, cobrindo desde a sintaxe inicial até conceitos essenciais para o mercado, como Orientação a Objetos, Tratamento de Exceções e Collections Framework.

📌 Módulos do Repositório

O conteúdo está organizado em módulos progressivos. Cada pasta contém exemplos práticos, explicativos e comentados:

1. 🔰 Sintaxe Básica (/SintaxeBasica)

Conceitos fundamentais da linguagem Java:

Declaração de variáveis e tipos primitivos (int, double, boolean, etc.)

Operadores aritméticos, relacionais e lógicos

Estruturas condicionais (if, else, switch-case)

Estruturas de repetição (for, while, do-while)

2. 🧩 Programação Orientada a Objetos - POO (/POO)

Base teórica e prática dos quatro pilares da POO:

Classes e Objetos: Construtores, atributos e métodos

Encapsulamento: Getters, Setters e modificadores de acesso (public, private, protected)

Herança: Reutilização de código usando extends

Polimorfismo: Sobrescrita (@Override) e sobrecarga de métodos

Abstração: Classes abstratas e Interfaces

3. 🛠️ Exemplo Prático de POO (/ExemploPraticoPOO)

E-comerce com POO

Aplicação das regras de negócio encapsuladas

4. 🛡️ Tratamento de Exceções (/TratamentoDeExcecao)

Como lidar com erros e situações imprevistas no código:

Uso de blocos try, catch e finally

Hierarquia de Exceções: Checked vs Unchecked Exceptions

Lançamento de exceções com a palavra-chave throw

Criação de Exceções Personalizadas (Custom Exceptions)

5. 📦 Collections Framework (/Collections)

Estruturas de dados nativas do Java para manipulação flexível de grupos de objetos:

List (ArrayList, LinkedList): Listas ordenadas que permitem elementos duplicados

Set (HashSet, TreeSet): Coleções que não permitem elementos duplicados

Map (HashMap, TreeMap): Estruturas no formato chave-valor

Métodos úteis de iteração e manipulação de coleções

💻 Como Executar os Exemplos

Pré-requisitos

JDK (Java Development Kit) versão 11 ou superior instalada.

Uma IDE de sua preferência (Eclipse, IntelliJ IDEA, VS Code).

Passos

Clone o repositório:

git clone https://github.com/seu-usuario/seu-repositorio.git


Acesse a pasta do projeto:

cd seu-repositorio


Execute os arquivos através da sua IDE ou via terminal:

javac NomeDoArquivo.java
java NomeDoArquivo
